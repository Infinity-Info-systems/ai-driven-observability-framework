# SRE Integration

## Purpose

SRE integration ensures observability supports service objectives, incident response, and post-incident improvement.

## Integration Points

- SLO and SLI tracking
- incident response
- error budget review
- operational review
- continuous improvement planning

## Operating Expectations

- every important service has a measurable objective
- alerts should map to user impact or service risk
- incidents should produce learning, not just closure
- reliability data should influence planning
