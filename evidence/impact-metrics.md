# Impact Metrics

## Metrics To Track

- mean time to detect
- mean time to recover
- alert noise ratio
- predictive alert precision
- incident recurrence rate
- signal-to-action time

## Reporting Notes

Track these metrics against a baseline so the team can show whether observability is becoming more predictive and more useful.

## Reporting Notes

- compare against baseline
- track trend after each improvement cycle
- link changes in metrics to concrete actions
