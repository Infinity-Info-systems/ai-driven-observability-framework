# Maturity Model

## Stage 1: Reactive

- monitoring is basic
- issues are found after impact
- response is mostly manual

## Stage 2: Instrumented

- key services emit telemetry
- alerts exist but are noisy
- incident handling is defined in parts

## Stage 3: Correlated

- signals are linked to services and outcomes
- incidents are reviewed consistently
- SLOs and SLIs are in use

## Stage 4: Predictive

- anomalies are detected early
- alerts are actionable
- response patterns are improved by learning

## Stage 5: Adaptive

- prediction is continuously tuned
- response becomes more automated
- observability and reliability improve together
